# Quelque indication pour ajouter des pages

> pour lancer le serveur il faut lancer la commmande :
> `mdbook serve --open`

> pour cree une pages :
> ajouter la pages dans SUMMARY.md, après enregistrement la pages va se crée dans le dossier src si le serveur est lancé, sinon tu le cree toi meme

> coté CI/CD dans le .github/workflow il ya un fichier, c'est la qu'il faut adapter si ya une probleme avce les plugin, ou l'ajout d'un plugin. (admonish qui est casser, toc, mermaid)
